### About Me

I'm an offensive-security practitioner focused on the security of **AI and Large Language Model (LLM) systems**. My background is in **web and Active Directory penetration testing**, and I'm now applying that adversarial mindset to **AI Red Teaming** — finding and exploiting weaknesses in deployed LLM applications.

I learn by breaking things in hands-on labs, then documenting how and why each attack works. Currently pursuing a **B.Sc. in Artificial Intelligence** while building practical offensive-AI and pentesting skills.

- 🔭 **Focus:** LLM red teaming — prompt injection, jailbreaking, indirect injection, response-filter bypass
- 🛡️ **Background:** Web pentesting (OWASP Top 10), Active Directory attacks, security lab engineering
- 🌱 **Learning:** Advanced AI attacks & defenses, adversarial ML, building a writeups portfolio
- 🎯 **Goal:** Grow as an AI Security / Red Team specialist
